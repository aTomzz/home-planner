# Home Studio

A home furniture simulator and measured design proposal. Published with GitHub Pages; no login is required.

- [Open the simulator](https://atomzz.github.io/home-planner/)
- [Open the latest design](https://atomzz.github.io/home-planner/design.html?bedRotated=1&bedroomWardrobe=1&livingCorner=1#explore)

This repository contains the static production build. The editable development project is maintained separately. No server or API keys are needed.

Layouts are saved in each visitor's browser, not in this repository. Use **Export layout** and **Import** to transfer a layout between browsers or from localhost. The proposal identifies a sample sofa when no saved layout is available.

The design references link to their original projects and award records and credit the photographs. Third-party photographs remain the property of their credited owners. Font licenses are included in `fonts/`.
